CASE STUDY 01

Plant E-Commerce & Management System

ระบบ E-Commerce และระบบบริหารจัดการร้าน ที่ออกแบบมาเพื่อรองรับผู้ใช้งานหลายบทบาท และการดำเนินงานภายในร้าน

ปัญหา

โปรเจกต์นี้ต้องรองรับผู้ใช้งานหลายบทบาท ทั้งลูกค้า ผู้ขาย ผู้ดูแลระบบ และเจ้าของร้าน รวมถึงต้องเชื่อมกระบวนการซื้อสินค้าออนไลน์ เข้ากับการจัดการออเดอร์ สต็อก และข้อมูลหลังบ้าน ภายในระบบเดียวกัน

แนวทางการแก้ปัญหา

ฉันออกแบบโครงสร้างระบบและ Workflow แยกตามบทบาทของผู้ใช้งานแต่ละกลุ่ม เพื่อให้แต่ละคนสามารถทำงานในส่วนของตนเองได้อย่างชัดเจน พร้อมเชื่อมโยงกระบวนการหน้าร้าน และระบบหลังบ้านเข้าด้วยกัน

บทบาทของฉัน

ฉันรับผิดชอบด้านการวิเคราะห์ Requirement และออกแบบ Workflow สำหรับผู้ใช้ 4 กลุ่ม ได้แก่ Customer, Seller, Admin และ Store Owner รวมถึงช่วยวางโครงสร้างการทำงานของระบบ ตั้งแต่หน้าร้านไปจนถึงหลังบ้าน

Technology ที่ใช้

ASP.NET Core C# SQL HTML CSS JavaScript

ผลงานและหลักฐาน

ตัวอย่างด้านล่างแสดงทั้ง Customer Flow และ Management Side เพื่อให้เห็นการทำงาน ตั้งแต่การซื้อสินค้าไปจนถึงการจัดการระบบหลังบ้าน

Customer Flow

เลือกสินค้า → เพิ่มลงตะกร้า → Checkout → ชำระเงิน → ติดตามสถานะคำสั่งซื้อ

Management Side

Seller จัดการสินค้าและออเดอร์ Admin ดูแลภาพรวมของระบบ และ Owner ตรวจสอบข้อมูลและภาพรวมการดำเนินงาน

ผลลัพธ์และสิ่งที่ได้เรียนรู้

โปรเจกต์นี้ทำให้ฉันได้ฝึกวิเคราะห์ Requirement ของผู้ใช้งานหลายกลุ่ม ออกแบบ Workflow แบบ End-to-End และเข้าใจมากขึ้นว่าการออกแบบระบบที่ดี ต้องคำนึงถึงทั้งประสบการณ์ของผู้ใช้ และการทำงานของระบบหลังบ้านควบคู่กัน

CASE STUDY 02

ScamGuard AI

ระบบที่นำ AI มาช่วยให้ผู้ใช้งาน เข้าใจความเสี่ยงจากมิจฉาชีพออนไลน์ และข้อความที่น่าสงสัย

ปัญหา

ผู้ใช้งานทั่วไปอาจได้รับข้อความที่น่าสงสัย จากหลายช่องทาง เช่น SMS, LINE หรือ Email แต่ไม่สามารถประเมินได้ง่ายว่าข้อความนั้น มีความเสี่ยงหรือเข้าข่ายมิจฉาชีพหรือไม่

แนวทางการแก้ปัญหา

ระบบถูกออกแบบให้รับข้อความที่ผู้ใช้สงสัย แล้ววิเคราะห์หารูปแบบที่อาจเกี่ยวข้องกับการหลอกลวง จากนั้นใช้ฐานความรู้และ AI ช่วยอธิบายเหตุผลของความเสี่ยง ให้อยู่ในรูปแบบที่ผู้ใช้งานทั่วไปเข้าใจได้

บทบาทของฉัน

ฉันมีส่วนร่วมในการออกแบบแนวคิดของระบบ และโครงสร้างการตอบกลับของ AI โดยประยุกต์ใช้ Machine Learning, RAG และ LLM เพื่อช่วยให้ระบบสามารถวิเคราะห์ข้อความ และอธิบายความเสี่ยงในรูปแบบที่เข้าใจง่าย

Technology ที่ใช้

Python Machine Learning LLM RAG NLP HTML/CSS/JS

ผลงานและหลักฐาน

ตัวอย่างหน้าจอ AI Assistant ซึ่งผู้ใช้งานสามารถสอบถามเกี่ยวกับ การหลอกลวงออนไลน์ ข้อความน่าสงสัย OTP Fraud และแนวทางป้องกันมิจฉาชีพได้

ผลลัพธ์และสิ่งที่ได้เรียนรู้

โปรเจกต์นี้ช่วยให้ฉันเข้าใจการนำ AI มาใช้กับปัญหาที่ใกล้ตัวมากขึ้น โดยเฉพาะการออกแบบคำตอบของระบบ ที่ไม่ใช่เพียงบอกว่าเสี่ยงหรือไม่เสี่ยง แต่ต้องอธิบายเหตุผลให้ผู้ใช้งานเข้าใจ และสามารถตัดสินใจต่อได้

CASE STUDY 03

Slide Me - Admin Side

ระบบบริหารจัดการบริการรถสไลด์ ในส่วนของผู้ดูแลระบบ

ปัญหา

ฝั่งผู้ดูแลระบบต้องจัดการข้อมูลหลายประเภท เช่น บัญชีผู้ใช้ คนขับ รถ ออเดอร์ และสิทธิ์การใช้งาน หาก Workflow ไม่ชัดเจนอาจทำให้ตรวจสอบข้อมูลยาก และเกิดความผิดพลาดระหว่างใช้งาน

แนวทางการแก้ปัญหา

ได้ออกแบบ Workflow ของฝั่ง Admin ให้ข้อมูลสำคัญถูกแยกเป็นหมวดหมู่ชัดเจน พร้อมจัดลำดับการเข้าถึงข้อมูลและ Permission เพื่อช่วยให้ผู้ดูแลระบบสามารถตรวจสอบ และจัดการข้อมูลได้ง่ายขึ้น

บทบาทของฉัน

ได้ออกแบบและประเมิน Workflow ในส่วนของผู้ดูแลระบบ เช่น การจัดการเอกสารคนขับ สถานะคำสั่งซื้อ การจัดการรถ และสิทธิ์การใช้งาน รวมถึงนำ Feedback จากผู้ใช้ มาช่วยปรับปรุง UX/UI ของระบบ

Technology ที่ใช้

React JavaScript CSS System Analysis UX/UI User Testing

ผลงานและหลักฐาน

ตัวอย่าง Dashboard และหน้าจอจัดการระบบ ที่ใช้สำหรับตรวจสอบข้อมูลสำคัญ และจัดการบัญชีผู้ใช้ คนขับ ออเดอร์ และ Permission

ผลลัพธ์และสิ่งที่ได้เรียนรู้

โปรเจกต์นี้ทำให้ฉันได้ฝึกมองระบบ จากมุมของผู้ดูแลระบบมากขึ้น รวมถึงการนำ Feedback จากผู้ใช้งาน มาปรับ Workflow และ UX/UI เพื่อให้การใช้งานมีความชัดเจน และลดความผิดพลาดระหว่างใช้งาน
