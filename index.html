CASE STUDY 01

Plant E-Commerce & Management System

ระบบ E-Commerce และระบบบริหารจัดการร้านต้นไม้ ที่รองรับผู้ใช้งานหลายบทบาท ตั้งแต่การซื้อสินค้า ไปจนถึงการจัดการระบบหลังบ้าน

โจทย์ของโปรเจกต์

โปรเจกต์นี้ต้องรองรับผู้ใช้งานหลายบทบาท ทั้ง Customer, Seller, Admin และ Store Owner ซึ่งแต่ละกลุ่มมีหน้าที่และการใช้งานที่แตกต่างกัน รวมถึงต้องเชื่อมกระบวนการซื้อสินค้าออนไลน์ เข้ากับการจัดการสินค้า ออเดอร์ สต็อก และข้อมูลหลังบ้านภายในระบบเดียวกัน

สิ่งที่พัฒนา

ระบบถูกแบ่งการทำงานตามบทบาทของผู้ใช้งาน โดยพัฒนาหน้าและฟังก์ชันสำหรับ Customer, Seller, Admin และ Store Owner ให้แต่ละกลุ่มสามารถเข้าถึงส่วนที่เกี่ยวข้องกับตนเอง พร้อมเชื่อมการทำงานระหว่างหน้าร้าน และระบบหลังบ้านเข้าด้วยกัน

ส่วนที่ฉันรับผิดชอบ

ฉันมีส่วนร่วมในการพัฒนาระบบ ทั้งส่วนหน้าเว็บไซต์และฟังก์ชันการทำงาน สำหรับผู้ใช้งานทั้ง 4 กลุ่ม รวมถึงระบบสินค้า ตะกร้าสินค้า Checkout การจัดการออเดอร์ และหน้าจอสำหรับจัดการระบบ โดยได้ทำงานกับโครงสร้าง MVC และเชื่อมต่อข้อมูลกับฐานข้อมูล MySQL

Technology & Tools

ASP.NET Core C# MySQL HTML CSS JavaScript

Project Preview

ตัวอย่างด้านล่างแสดงทั้งส่วนของ Customer และ Management Side เพื่อให้เห็นการทำงานของระบบ ตั้งแต่การเลือกซื้อสินค้า ไปจนถึงการจัดการข้อมูลหลังบ้าน

Customer Flow

เลือกสินค้า → เพิ่มลงตะกร้า → Checkout → ชำระเงิน → ติดตามสถานะคำสั่งซื้อ

Management Side

Seller สามารถจัดการสินค้าและออเดอร์ Admin ดูแลข้อมูลและการใช้งานของระบบ ส่วน Store Owner สามารถดูข้อมูล และภาพรวมการดำเนินงานของร้าน

What I Learned

โปรเจกต์นี้ทำให้ได้ฝึกพัฒนา Web Application ตั้งแต่การสร้างหน้าเว็บไซต์ การเขียนฟังก์ชัน การทำงานกับฐานข้อมูล และการพัฒนาระบบตามโครงสร้าง MVC รวมถึงได้เข้าใจการทำงานร่วมกันระหว่าง Frontend, Backend และ Database มากขึ้น

CASE STUDY 02

ScamGuard AI

Web Application ที่นำ AI มาช่วยวิเคราะห์ข้อความที่น่าสงสัย และอธิบายความเสี่ยงให้ผู้ใช้งานเข้าใจได้ง่ายขึ้น

โจทย์ของโปรเจกต์

ผู้ใช้งานทั่วไปอาจได้รับข้อความที่น่าสงสัย จากหลายช่องทาง เช่น SMS, LINE หรือ Email แต่ไม่สามารถประเมินได้ง่ายว่า ข้อความนั้นมีความเสี่ยง หรือเข้าข่ายมิจฉาชีพหรือไม่

สิ่งที่พัฒนา

ระบบถูกพัฒนาให้รับข้อความที่ผู้ใช้งานสงสัย แล้วนำข้อมูลไปวิเคราะห์หารูปแบบ ที่อาจเกี่ยวข้องกับการหลอกลวง จากนั้นนำ Machine Learning, RAG และ LLM มาช่วยวิเคราะห์และอธิบายเหตุผลของความเสี่ยง ให้อยู่ในรูปแบบที่ผู้ใช้งานทั่วไปเข้าใจได้

ส่วนที่ฉันรับผิดชอบ

ฉันมีส่วนร่วมในการออกแบบและพัฒนา Web Application รวมถึงแนวคิดและโครงสร้างการตอบกลับของ AI โดยประยุกต์ใช้ Machine Learning, RAG และ LLM เพื่อช่วยวิเคราะห์ข้อความ และแสดงผลการตรวจสอบให้ผู้ใช้งานเข้าใจได้ง่าย

Technology & Tools

Python Machine Learning LLM RAG NLP HTML/CSS/JS

Project Preview

ตัวอย่างหน้าจอ AI Assistant ที่ผู้ใช้งานสามารถใช้สอบถาม หรือวิเคราะห์ข้อมูลเกี่ยวกับ การหลอกลวงออนไลน์ ข้อความน่าสงสัย OTP Fraud และแนวทางป้องกันมิจฉาชีพ

What I Learned

โปรเจกต์นี้ทำให้ฉันได้เรียนรู้ การพัฒนา Web Application ที่นำ AI มาประยุกต์ใช้กับปัญหาที่ใกล้ตัว รวมถึงการออกแบบหน้าแสดงผล และคำตอบของระบบให้ผู้ใช้งาน สามารถเข้าใจผลการวิเคราะห์ และนำข้อมูลไปใช้ตัดสินใจต่อได้

CASE STUDY 03

Slide Me - Admin Side

ระบบบริหารจัดการบริการรถสไลด์ ในส่วนของผู้ดูแลระบบ ที่พัฒนาด้วย React และ Vite

โจทย์ของโปรเจกต์

ฝั่งผู้ดูแลระบบต้องจัดการข้อมูลหลายประเภท เช่น บัญชีผู้ใช้งาน คนขับ รถ ออเดอร์ และสิทธิ์การใช้งาน จึงต้องมีหน้าเว็บที่จัดข้อมูลให้เป็นหมวดหมู่ และสามารถเข้าถึงข้อมูลที่ต้องการได้ง่าย

สิ่งที่พัฒนา

พัฒนาหน้า Admin โดยแยกข้อมูลและฟังก์ชันออกเป็นส่วนต่าง ๆ เช่น Dashboard, Banner, Order และ Account Management เพื่อให้ผู้ดูแลระบบสามารถเข้าถึง และจัดการข้อมูลแต่ละประเภทได้ง่ายขึ้น

ส่วนที่ฉันรับผิดชอบ

ฉันมีส่วนร่วมในการพัฒนาหน้า Admin โดยใช้ React และ Vite เช่น Dashboard, Banner, Order และ Account Management รวมถึงปรับการจัดวางข้อมูลและ UX/UI ให้เหมาะกับการใช้งานของผู้ดูแลระบบ

Technology & Tools

React Vite JavaScript CSS UX/UI

Project Preview

What I Learned

โปรเจกต์นี้ทำให้ได้ฝึกพัฒนา Frontend ด้วย React และเข้าใจการแบ่งหน้า และส่วนประกอบต่าง ๆ ของระบบ Admin มากขึ้น รวมถึงได้ฝึกการจัดวางข้อมูล และปรับ UX/UI ให้เหมาะกับการใช้งานจริง
